# AI 单词闯关 · 八上英语

一个给初二学生用的英语单词闯关小游戏（单文件网页版，手机 / 电脑都能玩，不用装任何东西）。

打开方式：

- 双击 `index.html` 就能玩（离线可用）。
- 手机上用浏览器打开 Pages 地址即可（需要联网打开一次，之后可离线）。

## 目录说明

| 文件 / 目录 | 作用 |
| --- | --- |
| `index.html` | 整个游戏，全部内容都在这一个文件里 |
| `petimg/` | 宠物形象图片（鸡、兔、龟、熊猫、龙、凤凰、蛙） |
| `audio/` | 单词真人发音 MP3（1000 多个，安卓机上也能读出人声） |

## 功能

- 按课本单元闯关背单词，答对答题、连对有连击奖励。
- 养宠物：答对题目涨成长值，可以喂草料，宠物会跟着一起长大。
- 云存档：进度和成绩存在网上，换手机不会丢；也可以免注册直接玩（本机账号）。
- 好友互动：送礼物、排行榜、动态广场。
- 发音：点单词发音，优先用预生成的真人音（安卓也能听），没有预生成就用系统朗读。
